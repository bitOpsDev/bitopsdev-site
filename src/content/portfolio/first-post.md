**UI Signal Wave Toolkit** is a modular 3-in-1 waveform system built for Unity UGUI.

It includes three powerful systems in one package:
- **Signal Wave System** – Classic animated waveforms
- **Monitor Wave (Telemetry Scan)** – Persistent ECG/radar-style scanning displays
- **Sound Wave Meter** – Real-time audio reactive meters

### Features

**Signal Wave System**
- Sine, Cosine, Tangent waves
- Adjustable cycles, speed, phase, and amplitude
- Ribbon or dot rendering modes
- Gradient and color customization
- Global or local synchronization

**Monitor Wave (Scan System)**
- Persistent historical buffer with sweeping scan head
- Heartbeat-style curves included
- Adjustable sweep speed and BPM control
- Multiple scan head styles

**Sound Wave Meter**
- Real-time audio reactivity (AudioListener or AudioSource)
- Attack/release smoothing and noise gate
- Highly customizable visualization

### Modular & Lightweight
- Import only what you need
- No shaders required
- Works with Built-in Render Pipeline
- Optimized for runtime performance
- Full ScriptableObject workflow

### Demo Scenes Included
Interactive demos for each system with real-time inspector controls.
