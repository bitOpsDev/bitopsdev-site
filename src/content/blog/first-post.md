After a long time running **Info Gamer Hub**, I’ve finally launched the new **BitOpsDev** website.

This has been a long time coming. The old site had served its purpose well for tutorials and asset releases, but it was starting to feel outdated and high-maintenance. So I decided it was time for a fresh start with a proper home that better reflects where I’m at now.

### What’s New

The new site is cleaner, faster, and more focused. It’s built around three main sections:

- **Games** — My full game projects, including the one I’m currently working on
- **Portfolio** — Unity Assets, tutorial series, Blender work, and other creations
- **Journal** — Dev logs and behind-the-scenes updates like this one

I’m really happy with how it turned out. It feels more professional while still keeping that personal, in-development vibe I like.

### What’s Next

This is just the beginning. I’ll be regularly updating the site with new projects, assets, screenshots, and dev logs as I continue working on my current multiplayer game and preparing more content for the Unity Asset Store.

If you’ve been following along for a while — thank you. And if you’re new here, welcome! I’m excited to keep sharing the journey with you.

Let’s build something great together.
